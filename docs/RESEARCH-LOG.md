**這份文件的用途**：下一個 AI 或使用者要抽查、或被質疑「這個座標／電話是哪來的」時，不用重新研究一次。每項列出：套用了什麼、依據的網址、頁面日期、**逐字原文**，以及這句原文有沒有被核對過。

## 核對標記的意思

| 標記 | 意思 |
|---|---|
| 🟢 原始檔比對符合 | 我寫了腳本，把這句原文拿去和**抓回來的原始頁面**逐字比對（忽略空白與全形半形差異），找得到。括號裡是誰抓的：「我重新抓取」＝我自己重讀同一個頁面；「研究員抓取」＝只有研究員抓過，我是對他存下的原始檔比對 |
| 🟡 只有部分符合 | 引句用「…」分段，只有部分段落找得到 |
| ⚪ 原始檔找不到 | 研究員報告裡有這句，但抓回的檔案裡比對不到（可能是引句改寫過、頁面是 JS 渲染、或原始檔沒保留）。**要當作「研究員說的」，不要當成已驗證** |
| 🔵 我即時查詢 | 內政部座標查詢之類的 API，是我自己執行的結果，沒有存檔 |
| 🟣 圖片原文 | 公告是圖片，我用視覺讀取確認 |

> 原始檔比對在 2026-10-25 的工作階段進行。原始抓取檔（約 77 MB）沒有放進 repo，工作階段結束後就不在了，所以這份紀錄保留的是**逐字引句與比對結果**。
