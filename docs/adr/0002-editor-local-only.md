# 0002 編輯器只在本機跑

日期：2026-10-26｜狀態：已決定，已實作（2026-10-26）

## 背景

使用者希望規劃行程時有介面協助，公開頁面呈現最新結果。公開頁面是 GitHub Pages 的靜態網站。

## 決定

- 編輯器是 `tools/editor/` 的零依賴 Node 伺服器，只綁 `127.0.0.1`，只有規劃者本人使用；並且只接受 `Host` 為 `127.0.0.1`／`localhost` 的請求（其他回 403），避免網頁透過 DNS rebinding 打到它。
- 公開頁面維持純靜態，不加後端、不加登入，也不內建編輯模式。
- 編輯器透過寫檔與 git 把結果放到 `main`，公開頁面由 Pages 發布。

## 後果

- 好處：沒有認證、金鑰與權限問題；公開頁面攻擊面不變；不增加依賴。
- 代價：只有開著這台電腦的 WSL 才能編輯；家人無法直接編輯，只能看公開頁面。
- 編輯器不能對區網或外網開放，因為它有發布（push 到 `main`）的能力。
- 需要在本機安裝 Node。

## 考慮過的其他做法

- 公開頁內建編輯模式、用 GitHub API 寫回：要處理 token，公開頁面會多出能寫入的程式。
- 另架後端（Supabase、Firebase）：增加維運與費用，只有一位使用者，不值得。
