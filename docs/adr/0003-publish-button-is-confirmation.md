# 0003 編輯器的發布按鈕視為使用者確認

日期：2026-10-26｜狀態：已決定（尚未實作）

## 背景

全域規則與 `AGENTS.md` 規定：commit、push 一律先向使用者確認。編輯器要有「發布」按鈕，按下後自動 commit 並 push 到 `main`。

## 決定

- 在編輯器的確認視窗按下同意，視為使用者已確認這次 commit 與 push。確認視窗必須顯示異動摘要與可編輯的 commit 訊息，並在 `check.js` 通過後才出現同意鈕。
- 發布流程失敗時只顯示錯誤，不自動重試、不 `--force`、不改用其他路徑。
- commit 訊息不附 AI 署名。
- 只允許在 `main` 分支發布。
- 這項授權只涵蓋編輯器的發布按鈕。Claude 在對話中自行 commit、push，仍然要先問使用者。

## 後果

- 好處：改完直接發布，公開頁面最快更新。
- 風險：按錯就會 push。緩解方式是確認視窗列出異動，並且 push 失敗時不會強推，所有變更仍可由 git 還原。
- `AGENTS.md` 要寫明這個例外，避免和既有「先確認」規則矛盾。
